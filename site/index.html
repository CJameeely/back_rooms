PARAMETER LAB / BROWSER SIMULATION

Feel the lights run out.

Change the room duration, then scrub through time. The light states follow the runtime thresholds: flicker at 30% remaining, sequential shutoff at 5%.

This demonstration changes the website only. It does not edit your Unity project. It omits random flicker, penalties and discovery bonuses.

05 / DEVELOPMENT JOURNAL

What changed.
What it changed.

Reconstructed from the work in this project. These notes describe changes to the player’s experience, rather than website styling or unverified playtest claims.

20 OCT 2026
INTERACTION 01

Give the rooms a reason to exist.

An opening sequence introduces the repeating facility and R. Shen. Voiced archives separate puzzle rooms; reading pauses the countdown.

PLAYER EFFECT / CONTEXT BEFORE THE NEXT PUZZLE
20 OCT 2026
INTERACTION 02

A clue should survive its own prop.

The rotating plate receives a dedicated readable face. Its stand stays fixed while the plate and rear map rotate. The first room’s code HUD no longer follows the player into room two.

PLAYER EFFECT / LESS VISUAL INTERFERENCE
20 OCT 2026
INTERACTION 03

Objects belong to surfaces.

Generated equipment replaces six placeholder props. Mounting depth, desk contact, controls and the mirror’s support are adjusted while preserving interaction targets.

PLAYER EFFECT / CLEARER PHYSICAL AFFORDANCES
20 OCT 2026
INTERACTION 04

A person, not a sphere.

A posed human replaces the sphere-and-oval figure on the bed. A faceless Janitor replaces the capsule figure, faces the player on appearance and uses the original blink timing.
