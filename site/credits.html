PROJECT DOCUMENTATION

Sources & credits

Game project: CJ & Evan. The site documents the local Unity working tree, including changes not yet present on the remote repository.

Images and video

All game screenshots are in-engine captures from this project. The embedded recording is The_Last_Light_90s_Demo.mp4, recorded October 19, 2026. Character and prop screenshots were captured October 20. The recording predates the updated character assets.

Models

All eight character and equipment assets were generated by the user from project reference images. Web models are reduced / resized copies for interactive inspection. Neither character has a walk cycle in this version.

Code and diagrams

The script browser includes a snapshot of 13 core C# files. Relationships are curated direct references and are not a complete static call graph. Parameters distinguish field defaults from runtime overrides. The map is exported from 956 visible mesh parts in the running Unity level, preserving world positions. Ceilings are removed, height is capped at 1.7 m, materials use simplified colours and geometry is reduced for the browser. Narrative sets outside the physical level are excluded.

The earlier conceptual room figure used the Anatomy isometric geometry kit by Ryan, under the MIT license. It has been replaced by the actual Unity scene export. Model viewing uses Google's locally bundled model-viewer, version 4.4.0, under the Apache 2.0 license.

Course toolkit compatibility

The supplied CGDD toolkit was inspected to identify its data conventions. The repository includes the CGDD toolkit. This custom site uses a separately prepared source snapshot; its interactive script view does not use the toolkit’s bundle.js export. Do not overwrite this custom index.html with a template without keeping a backup.

Reflection

Development notes are reconstructed from project changes. Stage reflections are reserved for the student's own writing. Browser drafts are not published automatically.
